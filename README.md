# Word Formation — Reference

A static word-formation reference for students and teachers. This starter edition contains **17 curated word families (86 individual forms)** and **20 prefix/suffix entries**. It is not an exhaustive dictionary.

## Run locally

Open `index.html` in a modern browser. For more consistent local behavior, serve the folder using an HTTP server (for example, `python -m http.server 8000`) and open `http://localhost:8000`.

## Publish on GitHub Pages

1. Create a dedicated, public GitHub repository for the site (for example `word-formation-reference`). Do not upload private student data.
2. Upload `index.html`, `styles.css`, `app.js`, `data.js`, and `.nojekyll` to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Open the URL GitHub Pages shows after publishing.

The site requires no server, API key, third-party runtime, analytics or paid services. Word search and PT/EN definitions work offline after the files load; US pronunciation uses the browser's local speech synthesis support, so voice quality and offline availability depend on the installed browser and voices. Language preference is stored locally in the browser. Deep links use hashes like `#word=rely` and `#affix=un-`.

## Content and editorial guidelines

- Word families are curated entries, not automatically generated by concatenating arbitrary prefixes and suffixes
- A derived word can change meaning or grammatical function; do not treat all family members as interchangeable
- English definitions and Portuguese help are optional language modes; examples remain natural American English
- Avoid artificial examples, unnecessary punctuation in teaching cards and student-facing meta commentary
- Keep pronunciation user-triggered; consultation is not a right/wrong quiz, so no success/error sounds
- Review dictionary data and examples with a human editor before expanding the production catalog

## Files

- `index.html` — structure and accessibility labels
- `styles.css` — responsive dark design
- `app.js` — search, navigation, language toggle, audio, notes and deep links
- `data.js` — curated content, editable without changing application logic
- `.nojekyll` — lets GitHub Pages serve the static site as-is
